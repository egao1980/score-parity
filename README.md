# score-parity

A shared corpus of public-domain scores, plus assertions that every score-protocol format backend must pass: lossless round-trip, interop with an external notation program, and voice splitting.

**Status:** skeleton (0.0.1). The design is in the capability brief [cl-stack/docs/capabilities/score.md](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/score.md). The API and tests land through contract branches and team-solve.

```sh
cl-repo test --system score-parity
```
